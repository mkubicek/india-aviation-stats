# Observation

The first cut of `mappings.yaml` filed Kalaburagi/Gulbarga airport under the key
`KLH`. But `KLH` is **Kolhapur's** IATA code (Maharashtra); Kalaburagi/Gulbarga
(Karnataka) is **GBI**. The raw data carries both `KALABURAGI` (2022-2025) /
`KALABURAGI KARNATAKA` (2019-2022) and a separate `KOLHAPUR` (2018-2026) — two
physically distinct airports ~500 km apart.

# Interpretation

Mapping the unmapped `KOLHAPUR` label to `KLH` while Kalaburagi's data already sat
under `KLH` would have merged two different airports into one series — a silent
erase. This was caught during the airport-label verification pass.

# Decision

Kalaburagi moved to **GBI** (variants `KALABURAGI`, `KALABURAGI KARNATAKA`); a fresh
**KLH** rebuilt for Kolhapur (variant `KOLHAPUR`). Distinct entities, never merged.

# Evidence

- Kalaburagi Airport = GBI / VOGB — https://en.wikipedia.org/wiki/Kalaburagi_Airport
- Kolhapur Airport (Chhatrapati Rajaram Maharaj) = KLH / VAKP —
  https://en.wikipedia.org/wiki/Kolhapur_Airport

# Falsification

`distinct-airports-not-merged` (airports=[GBI, KLH]): re-open if either disappears
from Layer 1 or the two collapse into one canonical key.

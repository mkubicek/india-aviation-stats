# Observation

Purnea Airport (Bihar, IATA PXN) appears under two source spellings: `PURNIA
AIRPORT` (2025-09 → 2025-11) and `PURNEA` (2025-12 onward). Same physical airport,
disjoint in time.

# Interpretation

A spelling change, not two airports — the labels never co-occur, so resolving both
to PXN is safe.

# Decision

`PURNEA` and `PURNIA AIRPORT` → canonical **PXN**.

# Evidence

- Purnea Airport (Chunapur), IATA PXN — https://en.wikipedia.org/wiki/Purnea_Airport

# Falsification

`month-disjoint-rename`: re-open if the two spellings ever report in the same
month, which would imply they are not just a spelling change of one airport.

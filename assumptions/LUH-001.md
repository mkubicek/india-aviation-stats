# Observation

The single source label `LUDHIANA` means two different airports over time. Through
2025-09 it is the old **Sahnewal** field (IATA LUH) running tiny UDAN ops (tens to
low-hundreds of pax/mo). From 2026 it is the new **Halwara International** (IATA HWR,
inaugurated 2026-02): the 2026-05 row jumps to ~3,600 pax, ~40× the Sahnewal era.

Raw provenance:
- `LUDHIANA` 2025-09 ≈ 44 pax (Sahnewal UDAN)
- `LUDHIANA` 2026-05 ≈ 3,604 pax (Halwara)

# Interpretation

Same shape as Goa: one label, two airports, disjoint in time. A flat alias would
merge a defunct field with a brand-new airport. Split with validity windows so
neither is erased and Halwara shows up as a genuine newcomer.

# Decision

`LUDHIANA` (≤2025-12) → **LUH** (Sahnewal); `LUDHIANA` (≥2026-01) → **HWR**
(Halwara). Windowed variants in `mappings.yaml`.

# Evidence

- Halwara/Ludhiana International = HWR - https://en.wikipedia.org/wiki/Ludhiana_(Halwara)_International_Airport
- Sahnewal Airport = LUH - https://en.wikipedia.org/wiki/Sahnewal_Airport

# Falsification

`month-disjoint-rename` (labels=[LUDHIANA]): the LUH-era and HWR-era windows are
month-disjoint by construction. Re-open if the label's resolution windows ever
overlap, or if Sahnewal resumes scheduled service concurrently with Halwara.

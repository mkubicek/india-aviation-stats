# Observation

The January 2025 DGCA domestic city-pair workbook contains a
`HYDERABAD`–`HYDERABAD` row with zero passengers to City2 and two passengers
from City2.

# Interpretation

Both endpoints resolve to the same physical airport, HYD. The row therefore
cannot describe an inter-airport domestic passenger journey and would create a
two-passenger directed self-loop plus four false endpoint movements.

# Decision

Exclude this exact source row before constructing both
`domestic_route_monthly.csv` and `airport_monthly.csv`. The exclusion is keyed
by source labels and period in `mappings.yaml`; it is not a chart-specific
filter.

# Evidence

- DGCA normalized source row: `data/raw/aviation/aggregated/domestic/city.csv`,
  2025-01, `HYDERABAD` → `HYDERABAD`, directions 0 and 2.
- Source fingerprint:
  `data/sources_manifest.csv` (`DOM CITYPAIR DATA, JANUARY 2025.xlsx`).

# Falsification

`source-self-loop-excluded`: re-open if the exact source row disappears, no
longer resolves to HYD at both endpoints, or is no longer declared in the
table-driven route exclusions.
